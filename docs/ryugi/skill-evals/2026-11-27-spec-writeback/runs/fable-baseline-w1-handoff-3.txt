## 4. Run the whole chain on the finished branch

The browser check proved that a download works. The 20000-note claim needs raw output from HEAD, so I drive the chain with real sign-in and seeded data.

```bash
W=.artideck/sdd/2026-11-10-export-design; OUT=.artideck/artifacts/verify/export/outputs/stream-20000.txt
pnpm dev > $W/dev.log 2>&1 & echo $! > $W/dev.pid; sleep 5
pnpm db:seed -- --user a@verify.test --notes 20000 && pnpm db:seed -- --user b@verify.test --notes 3
{
set -x
date -u +%FT%TZ; git rev-parse --short HEAD
curl -s -c $W/a.jar -X POST localhost:8787/api/dev/login -d 'email=a@verify.test' -o /dev/null -w '%{http_code}\n'
curl -s -c $W/b.jar -X POST localhost:8787/api/dev/login -d 'email=b@verify.test' -o /dev/null -w '%{http_code}\n'
curl -s -b $W/a.jar -D - -o $W/a.csv localhost:8787/api/export.csv -w 'ttfb=%{time_starttransfer}s total=%{time_total}s bytes=%{size_download}\n'
python3 -I -c "import csv,sys; r=list(csv.reader(open(sys.argv[1],encoding='utf-8',newline=''))); print('header',r[0]); print('records',len(r)-1,'unique_ids',len({x[0] for x in r[1:]}),'bad_width',sum(len(x)!=4 for x in r)); print('quoted_fields_roundtrip',sum(any(c in f for c in ',\"\n') for x in r[1:] for f in x))" $W/a.csv
curl -s -b $W/b.jar -o $W/b.csv localhost:8787/api/export.csv -w '%{http_code}\n'
python3 -I -c "import csv,sys; a={x[0] for x in list(csv.reader(open(sys.argv[1],newline='')))[1:]}; b=[x[0] for x in list(csv.reader(open(sys.argv[2],newline='')))[1:]]; print('b_records',len(b),'b_ids_in_a',len(a&set(b)))" $W/a.csv $W/b.csv
curl -s -o /dev/null -w 'anon=%{http_code}\n' localhost:8787/api/export.csv
} > $OUT 2>&1
kill $(cat $W/dev.pid); rm $W/a.csv $W/b.csv $W/a.jar $W/b.jar $W/dev.pid $W/dev.log; cat $OUT
```
