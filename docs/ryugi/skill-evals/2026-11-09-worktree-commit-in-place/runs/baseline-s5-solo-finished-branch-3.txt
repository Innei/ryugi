### 2. Move the changes, not copy them

```bash

```

Assumed: it stashes both files, and the checkout is now clean of my changes.

### 3. Create the worktree with the native tool

`EnterWorktree(name: "fix-date-format")`

Assumed: it creates `.claude/worktrees/fix-date-format` on a new branch (say `worktree-fix-date-format`) from HEAD, which is `feat/offline`, and switches the session into it. I need `main` as the base, not `feat/offline`. The new branch has no commits and no changes of mine, so re-pointing it is safe:

```bash
git switch -C fix/date-format main
```

Assumed: it switches to `fix/date-format` at the `main` tip.

### 4. Bring the changes in

```bash

```

Assumed: it applies cleanly, because `main` has no conflicting edits to `src/date/format.ts`.

Then verify both sides:

```bash
git status --porcelain
```

Assumed:
- The worktree shows ` M src/date/format.ts` and `?? src/date/format.test.ts`.

`ExitWorktree(action: "remove")`

Assumed: there are no uncommitted changes, so it succeeds without `discard_changes`. It returns the session to `/Users/p/git/notes-app` and deletes the worktree directory and its auto-created branch. `fix/date-format` stays, because it is pushed and the PR uses it.
