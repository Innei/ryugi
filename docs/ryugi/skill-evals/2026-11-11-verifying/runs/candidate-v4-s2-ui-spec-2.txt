## 3. Output claim: persistence on the running dev server

**Bash**
```bash
cd /Users/p/git/notes-app
EV=.ryugi/artifacts/verify/notification-settings/evidence; mkdir -p $EV
B=http://localhost:5173/api/prefs
H='content-type: application/json'
{
  echo "from: local dev $B @ $(git rev-parse --short HEAD)"; date -u +%Y-%m-%dT%H:%M:%SZ
  echo; echo '$ GET (before)'; curl -s $B | tee /tmp/prefs-before.json; echo
  echo; echo '$ PATCH {"notifications":{"email":false}}'
  curl -s -o /dev/null -w 'HTTP %{http_code}\n' -X PATCH -H "$H" -d '{"notifications":{"email":false}}' $B
  echo; echo '$ GET (after)'; curl -s $B | tee /tmp/prefs-after.json; echo
  echo; echo '$ diff before after (other keys must be unchanged)'; diff <(jq -S . /tmp/prefs-before.json) <(jq -S . /tmp/prefs-after.json)
  echo; echo '$ restore original value'
  curl -s -o /dev/null -w 'HTTP %{http_code}\n' -X PATCH -H "$H" -d "{\"notifications\":{\"email\":$(jq .notifications.email /tmp/prefs-before.json)}}" $B
  curl -s $B | jq -S . | diff - <(jq -S . /tmp/prefs-before.json) && echo "restored: identical to before"
} > $EV/prefs-persist.txt 2>&1; cat $EV/prefs-persist.txt
```
*Assumed output:* PATCH returns `HTTP 200`. The after-GET shows `notifications.email: false`. The diff shows only that one line changed. The restore returns `HTTP 200` and prints `restored: identical to before`.
