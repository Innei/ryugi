**4. `shell` — add the regression before editing the exporter**

```sh
cat >> test/export.test.ts <<'EOF'

it('delivers the first CSV note before reading the rest of a large account', async () => {
  const store = makeStore()
  let read = 0

  vi.spyOn(store, 'iterateNotes').mockImplementation(async function* () {
    for (let id = 1; id <= 200_000; id++) {
      read++
      yield makeNote({ id: String(id), title: `Note ${id}` })
    }
  })

  const csv = exportNotes(store, 'account-1')
  try {
    const header = await csv.next()
    expect(header.value).toContain('updatedAt')
    const first = await csv.next()
    expect(first.value).toContain('Note 1')
    expect(read).toBe(1)
  } finally {
    await csv.return(undefined)
  }
})
EOF
```

Assume exit `0`. The test counts notes requested from the store. It has a deterministic failure condition and does not need to exhaust the Mac’s memory.
