5. **Shell — add the regression before touching production code**

   ```sh
   cat >> test/export.test.ts <<'EOF'

   it('writes a 200k-note export as it reads the notes', async () => {
     const total = 200_000
     let rowsWritten = 0
     const firstNote = note(0)

     function* iterateNotes() {
       yield firstNote
       if (rowsWritten !== 2) {
         throw new Error('Requested the second note before writing the header and first note')
       }
       for (let id = 1; id < total; id++) {
         yield note(id)
       }
     }

     await exportNotes({ iterateNotes }, async () => {
       rowsWritten++
     })

     expect(rowsWritten).toBe(total + 1)
   })
   EOF
   ```

   The fixture produces notes lazily, and the writer retains only a count. The test can expose the eager read without exhausting the Mac’s memory.
