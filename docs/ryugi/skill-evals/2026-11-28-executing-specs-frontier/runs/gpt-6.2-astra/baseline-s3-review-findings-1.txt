**3. Reproduce the read-ahead failure through `exportNotes`.**

Assume `src/export.test.ts` already imports Vitest’s `test` and `expect`, `exportNotes`, and a `makeNote` fixture. The regression uses a lazy 200,000-note source and interrupts the destination on its first data row. This makes the number of notes read deterministic without depending on the Mac running out of memory.

```sh
cat >> src/export.test.ts <<'EOF'

test('a 200k-note export writes its first note before reading the whole account', async () => {
  let notesRead = 0
  async function* iterateNotes() {
    for (let index = 0; index < 200_000; index++) {
      notesRead++
      yield makeNote({ id: String(index), title: `note ${index}` })
    }
  }
  const store = {
    iterateNotes,
    async allNotes() {
      const notes = []
      for await (const note of iterateNotes()) notes.push(note)
      return notes
    },
  }

  let writes = 0
  const stopped = new Error('destination closed after first note')
  await expect(exportNotes(store, async () => {
    if (++writes === 2) throw stopped
  })).rejects.toBe(stopped)

  expect(writes).toBe(2)
  expect(notesRead).toBeLessThanOrEqual(256)
})
EOF
```
