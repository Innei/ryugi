**Step 1 — Decide and ledger the ruling.**

The spec mandates "one row per note: id, title, updatedAt" and is silent on escaping. A title containing a comma or newline would silently split or merge rows; that violates the spec's own one-row-per-note contract, so silence here is a gap I must rule on, not a reason to emit raw bytes.

Append to `.artideck/sdd/2026-11-10-export-design/progress.md`:

```
Ruling: CSV quoting — a title can contain a comma, newline, or double quote; the spec mandates only "one row per note: id, title, updatedAt" and is silent on escaping. Per RFC 4180, a field is wrapped in double quotes when it contains a comma, newline, or double quote, and internal double quotes are doubled. — cost if wrong: a non-RFC-4180 consumer would misparse quoted fields, but standard CSV importers accept this, whereas emitting raw titles would silently split/merge rows on real data.
```

**Step 4 — Implement minimal RFC 4180 quoting.**

```ts
function escapeCsvField(field: string): string {
  return /[",\n\r]/.test(field)
    ? '"' + field.replace(/"/g, '""') + '"'
    : field;
}

export function exportCsv(notes: Note[]): string {
  const lines = ['id,title,updatedAt'];
  for (const n of notes) {
    lines.push([n.id, escapeCsvField(n.title), n.updatedAt].join(','));
  }
  return lines.join('\n') + '\n';
}
```
