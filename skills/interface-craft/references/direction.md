# Deriving a product-specific design direction

These five lenses are **reasoning prompts**, not five compulsory questions for your human partner. Reuse information already present in the brief, the existing project, accepted designs and its design system. Inferences are your decisions, not user approvals. Ask only when an unresolved choice materially changes the result, using the existing Brainstorming process.

| Lens | Evidence to consult | Actionable result |
| --- | --- | --- |
| Product | Task, audience, work frequency, real data, primary action | The primary job the screen optimizes |
| Character | Voice, audience, existing identity, environment | Two or three concrete attributes shaping decisions |
| World | Domain objects, media, work context and physical metaphors | Visual language rooted in the product |
| Moments | Attention, risk, key insight, data or product imagery | One or two intentional focal areas, if needed |
| Signature | Current brand, recurrent workflow, domain-specific interaction | Meaningful repeated detail, or explicitly none |

Connect direction to concrete choices: layout, hierarchy, density, copy, palette, contrast, typography, spacing, imagery, motion, states. If a lens has no meaningful practical consequence, do not manufacture one.

## Example: incident monitoring dashboard

- **Product:** An on-call engineer locates an incident and assesses its impact quickly.
- **Character:** Exact, steady, operational.
- **World:** Diagnostic instruments, time-series and service dependencies.
- **Moments:** The active incident and the event-time graph establishing when failure started.
- **Signature:** A consistent incident timeline marker tied to actual events.

This might justify dense navigation, aligned data, clear incident status and restrained visual surroundings; those are outcomes of this product, not mandatory tokens to copy into other apps.

## Existing choices outrank defaults

Priority: direct current requirements and accepted decisions → project design system, platform conventions and existing brand → observed product needs → newly inferred direction.

Deliberate gradients, purple, translucent materials, serifs and animations are not inherent faults. A useful existing screen is not a blank canvas. When a visual direction is already settled, continue it instead of creating a new brand each round.

## Exploring direction on an Artboard

A coherent direction comparison may alter several linked visual properties because that *is* the question. Label and explain what differentiates each concept beyond color. Once a direction is selected, treat it as fixed while comparing one layout or interaction dimension per group. Use real product copy and representative data; not randomized template text or speculative features.

Do not force a signature detail onto every product. Do not present design intent as another formal approval gate outside the existing Artboard choices.
